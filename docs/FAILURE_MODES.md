# 失败模式与兜底

## 1. 官网抓取失败

- 记录 `source_health`；
- 连续失败达到阈值生成 `SOURCE_FAILED`；
- 自动切换到下一级策略；
- 最后进入人工处理，不伪造“已同步”。

## 2. 项目匹配不确定

中标公告与历史项目匹配置信度不足时：

- 不自动回填正式数据；
- 生成 `HUMAN_REVIEW_REQUIRED`；
- 同屏展示候选项目和原公告。

## 3. AI 提取冲突

官网、招标文件、源表字段不一致时：

- 保存所有来源；
- 生成 `DATA_CONFLICT`；
- 不静默覆盖；
- 人工选择正式值，保留审计。

## 4. Source Pointer 不能深链

- 仍保存文件/Sheet/页码/行号；
- UI 明确显示定位文字；
- 不伪造不存在的链接。

## 5. AI 服务不可用

- 搜索降级为结构化+关键词；
- 到期/截止/异常规则继续工作；
- 不影响原表和原文件使用。

## 6. 向量服务不可用

- 不影响结构化查询；
- 相似项目功能暂时降级；
- 搜索结果标明“语义排序暂不可用”。

## 7. 外部来源内容被删除

关键公告可配置保存文本快照、Hash 或文件副本；UI仍保留原 URL 和抓取时间。
