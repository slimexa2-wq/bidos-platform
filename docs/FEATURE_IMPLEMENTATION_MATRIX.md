# 功能落地矩阵

这份表用于防止“效果图里有，开发时发现做不了”。每一个 UI 功能在定版前都要对应数据源、实现方式、失败兜底和人工边界。

| 用户功能 | 数据从哪里来 | 核心实现 | 失败时怎么办 | 人工边界 |
|---|---|---|---|---|
| 盲投新项目发现 | 官方站/API/RSS/第三方 | Connector + Ingestion + 去重 | 来源健康告警，切浏览器或人工 | 人确认是否关注/参与 |
| 自动填盲投表 | 公告 + 招标附件 + 原表 | 字段抽取 + Source Pointer + 表写回适配器 | 标记待核验，不静默覆盖 | 关键金额/截止时间核验 |
| 原公告跳转 | URL/深链接 | Source Pointer | 无深链时打开来源首页/文件并提示位置 | 人核验原文 |
| 源表具体位置 | Sheet/Record/Row ID | Source Pointer | 平台不支持深链时显示 Sheet+行号 | 人在原表处理 |
| 更正公告提醒 | 网站变化 | Hash/Diff + 规则 + AI摘要 | 来源失败告警 | 人判断业务影响 |
| 中标公告回填 | 中标公告 | 项目实体匹配 + 字段提取 | 匹配低置信度进入待确认 | 人确认串项目风险 |
| 项目到期提醒 | 历史项目期限 | 规则引擎 | 缺日期则提示补数据 | 人决定是否跟进 |
| 保证金异常 | 台账 + 应退日期 | 规则引擎 | 缺应退时间则不误报 | 人与财务确认 |
| 文件解析 | PDF/DOCX/XLSX/图片 | Docling/OCR | 解析失败保留原文件 + 人工标记 | 关键条款人工核验 |
| 智能检索 | 项目/文件/表/公告/实体 | SQL + trigram + pgvector + reranker | 搜索降级为结构化/关键词 | 人可回原始证据 |
| 相似项目 | 项目特征 + 文档向量 | BGE-M3 + reranker | 无足够数据时明确提示 | 人判断是否真正可比 |
| 竞对分析 | 竞对表 + 中标公告 | 实体统一 + 项目关联 + 统计 | 名称冲突进入实体待合并 | 人确认别名和项目归属 |
| 报价决策参考 | 历史价格/失败原因/竞对/甲方 | Evidence Aggregator + LLM | 数据不足列为“不确定” | 人最终报价 |
| 项目评估 | 招标文件+公司能力+历史 | 规则 + 检索 + AI | 低置信度项全部人工确认 | 人最终参与决策 |
| 标书资料查找 | 资料库/历史标书 | 索引 + Source Pointer | 找不到就明确缺资料 | 人选择正式引用内容 |
| 标书内容辅助 | 招标要求+已审核资料 | LLM + 模板/章节上下文 | 不自动写正式文件 | 人审核和正式提交 |
| 整标检查 | 当前标书 + 招标文件 | 规则 + 文本一致性检查 + AI | 无法判断则列待确认 | 人最终质检 |
| 结果复盘 | 中标结果 + 当时决策 + 报价 | 自动对比 + 人工原因 | 不推测不可验证原因 | 人确认真实失标原因 |
| 经验沉淀 | 人工修正/结果 | Feedback + Audit | 不直接自动改生产规则 | 管理员审核后生效 |

## 定版原则

1. 没有明确数据来源的功能，不进正式版本。
2. 没有失败兜底的自动化，不允许静默运行。
3. 没有 Source Pointer 的关键 AI 结论，只能标记为“参考”。
4. AI 不替代是否参与、报价、风险接受和正式提交。


## v0.3 新增：项目结束日期与持续到期提醒

| 功能 | 数据来源 | 实现 | 失败/不确定时 | 人工职责 |
|---|---|---|---|---|
| 项目结束日期 | 中标公告、合同、服务期限、人工 | 标准化为 `project_end_at` + 日期类型 | 只有服务期限时标记为预计；日期冲突进入人工核验 | 确认关键日期 |
| 90天到期提醒 | 项目结束日期 | 规则引擎每天计算；90天内生成持久事件 | 结束日期未知则提示补充，不猜 | 续签/关闭跟踪 |
| 新公告解除提醒 | 新招标公告 + 项目实体匹配 | 新公告与历史项目匹配成功后关闭原到期事件并转为新机会 | 匹配置信不足不自动关闭 | 确认疑似匹配 |

## v0.3 新增：投标保证金退回台账

| 功能 | 数据来源 | 实现 | 失败/不确定时 | 人工职责 |
|---|---|---|---|---|
| 保证金金额 | 投标项目计划、招标文件、缴纳记录 | 结构化台账 | 金额冲突进入人工核验 | 确认金额/标段 |
| 应退日期 | 招标文件退还条款、明确业务规则、人工 | 规则解析 + 日期计算 | 条款有歧义则不自动算 | 确认应退日期 |
| 退回提醒 | 应退日期 + 实际到账 | 前3天提示，逾期高优先级持久事件 | 无应退日期时提示补录 | 到账确认 |
| 实际退回 | 财务记录/到账凭证 | 写入 `actual_refund_at` 并关闭事件 | 无凭证仍保持未结清 | 确认到账和凭证 |
