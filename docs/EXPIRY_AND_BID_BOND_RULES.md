# 项目结束日期与投标保证金规则

## 一、项目结束日期

### 数据来源优先级

1. 合同 / 中标公告中明确的开始、结束日期；
2. 招标文件明确服务期限 + 已确认开始日期；
3. 人工录入；
4. 仅有服务期限时可生成“预计结束日期”，必须标记 `estimated`。

### 提醒逻辑

- `project_end_at - 90天`：开始进入首页持续提醒；
- 30天内：提醒优先级升高；
- 已过结束日期但没有新公告：继续提醒；
- 以下任一条件关闭：
  - 新招标公告与原项目成功匹配；
  - 业务确认续签；
  - 人工关闭。

“已读”不等于“已解决”。

## 二、投标保证金退回

### 核心字段

项目、标段、金额、缴纳日期、结果日期、应退日期、实际退回日期、负责人、状态、来源证据。

### 应退日期

系统可从招标文件退还条款中提取，但只有规则足够明确时才自动计算；存在歧义时进入人工确认。

### 提醒

- 应退日前3天：提醒；
- 应退日：提醒；
- 逾期：高优先级持续提醒；
- 实际到账并确认后：关闭。

### 审计

实际退回确认必须记录操作人、时间、到账凭证 / 财务记录 Source Pointer。
